## こんな事業者が対象

山形市内で事業を営む**中小企業者**（法人・個人事業主）。資金の種類によっては創業予定者も対象。
市税に未納がないことが条件。

---

## 融資制度一覧

### ① 産業振興資金

| 項目 | 内容 |
|------|------|
| 対象 | 市内で事業を営む中小企業者 |
| 融資限度額 | 運転資金：100万〜3,000万円 ／ 設備資金：100万〜8,000万円 |
| 融資利率 | 運転資金 1.7%・設備資金 1.5%（いずれも固定） |
| 保証料補給 | **市が6割補給** |
| 融資期間 | 運転資金7年以内・設備資金15年以内（据置2年以内） |

### ② 特定創業支援資金

創業支援事業による証明を受けた起業予定者・創業後5年未満の方向け。

| 項目 | 内容 |
|------|------|
| 融資限度額 | 100万〜2,000万円 |
| 融資利率 | **1.1%**（固定） |
| 保証料補給 | **市が全額補給** |
| 融資期間 | 10年以内（据置2年以内） |

### ③ 経営支援資金

売上高等が前年同期比で5%以上減少している中小企業者向け。

| 項目 | 内容 |
|------|------|
| 融資限度額 | 100万〜4,000万円 |
| 融資利率 | 2.1%（固定） |
| 保証料補給 | **市が4割補給** |
| 融資期間 | 10年以内（据置2年以内） |

### ④ 中心市街地活性化支援資金

山形市が指定する中心市街地区域内で事業を営む事業者向け。

| 項目 | 内容 |
|------|------|
| 融資限度額 | 100万〜4,000万円 |
| 融資利率 | **1.3%**（固定） |
| 保証料補給 | **市が6割補給** |
| 融資期間 | 10年以内 |

## 申し込みのポイント

- 申込窓口は**取扱金融機関**（山形銀行・荘内銀行・きらやか銀行・山形信用金庫・商工組合中央金庫山形支店）
- 特定創業支援資金は創業支援事業による**証明書**の取得が必要（山形市経済部産業政策課またはやまがた創業・企業承継サポートセンターに相談）
- 経営支援資金は前年同期比5%以上の売上減少を証明する書類が必要
