## こんな方が対象

以下をすべて満たす方：

- **小学生以下の子ども**（出産予定含む）がいる世帯
- 千葉市内の**指定高経年団地**へ転居すること（同一団地内の転居は対象外）
- **所得制限なし**

---

## 補助内容

| 項目 | 内容 |
|------|------|
| **補助上限額** | **30万円** |
| 補助対象費用 | 中古住宅購入費・賃貸住宅賃料（賃料・敷金・礼金・共益費・仲介手数料）・引越費用・リフォーム費用 |
| 対象住宅 | 中古住宅の購入または賃貸（**新築は対象外**） |

### 補助対象費用の詳細

| 費用の種類 | 補助対象 |
|-----------|---------|
| 中古住宅の購入費 | ✓ |
| 民間賃貸の賃料・礼金・敷金・仲介手数料 | ✓ |
| 引越し費用 | ✓ |
| リフォーム費用 | ✓ |
| 新築住宅の購入費 | ✗（対象外） |

---

## 対象団地

千葉市内**6区（中央・花見川・稲毛・若葉・緑・美浜）**に**40以上の指定高経年団地**があります。
対象団地の詳細リストは公式サイトまたは窓口でご確認ください。

---

## 申請情報

| 項目 | 内容 |
|------|------|
| **受付開始** | **令和8年6月1日** |
| **受付終了** | 令和9年2月28日（消印有効）／窓口持参は令和9年2月26日まで |
| ⚠️ 予算上限 | 予算到達次第終了 |

---

## 新婚世帯向けには最大60万円の制度もあり

千葉市の同一事業で、**新婚世帯向けには最大60万円**（子育て世帯の2倍）の補助枠が別途あります。結婚直後に子育てを予定している世帯は新婚世帯枠も確認を。

---

## 申し込みのポイント

1. **所得制限なし**のため、幅広い世帯が対象
2. 購入・賃貸・引越し・リフォームの費用を合算して申請できるため、複数費用を組み合わせて上限30万円まで活用可能
3. 団地立地は郊外が多いため、通勤・通学アクセスを事前確認
4. 千葉市の太陽光・蓄電池補助（太陽光4.5万・蓄電池7万）・耐震改修補助（最大115万円）との**組み合わせも可能**
