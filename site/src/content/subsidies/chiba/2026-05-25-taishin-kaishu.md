## こんな方が対象

### 耐震診断補助

- **昭和56年（1981年）5月31日以前の耐震基準**で建設された木造住宅の所有者
- 千葉市内の住宅

### 耐震改修工事補助

- **平成12年（2000年）5月31日以前の耐震基準**で建設された木造住宅
- 耐震性が基準未満と診断された住宅の改修工事を行う方

---

## 補助内容

### ① 耐震診断補助

| 項目 | 内容 |
|------|------|
| **補助率** | 診断費用の **4/5** |
| **補助上限額** | **96,000円（9.6万円）** |
| 募集戸数 | 7戸 |
| **受付期間** | **令和8年5月1日〜5月29日**（受付中） |

### ② 耐震改修工事補助

| 項目 | 内容 |
|------|------|
| **補助率** | 工事費の **4/5** |
| **補助上限額** | **115万円** |
| 二段階改修 | 段階ごとに **57.5万円** |
| リ・バース60利用時 | 半額（57.5万円） |
| 募集戸数 | **27戸** |
| **受付期間** | **令和8年5月1日〜5月29日**（受付中） |

---

## 申請のポイント

1. **現在受付中（〜5月29日）**。枠が27戸と限られており、早めの申請を強く推奨
2. 耐震診断から始めて現状を把握し、その結果で改修補助申請へ進む流れが一般的
3. 二段階改修は一度の工事で全完了が難しい場合に活用できる（段階ごとに57.5万円）
4. 国の補助制度（地域型住宅グリーン化事業等）との併用を工務店に相談

⚠️ 令和8年度の募集戸数は限定（改修27戸・診断7戸）。早い者勝ちの先着順の可能性があるため今すぐ問い合わせを。
