## こんな人が対象

- 弥富市内の住宅に蓄電池を新規設置する個人
- 市内に居住している住宅所有者または居住者
- 太陽光発電システムとの組み合わせを検討している方

## 弥富市の補助金について（2026年度）

2026年度の弥富市の蓄電池補助金（定置用リチウムイオン蓄電システム）は、予算到達のため受付終了しています。

### 利用可能な代替・併用補助

弥富市での蓄電池導入を検討する場合は、**愛知県や国の補助金制度**の活用をお勧めします。

## 愛知県の蓄電池補助制度

愛知県では「住宅用地球温暖化対策設備導入促進費補助金」で蓄電池補助を実施しており、市町村との協調補助も行っています。

| 項目 | 内容 |
|------|------|
| **補助対象** | 定置用リチウムイオン蓄電システム |
| **補助額** | 市町村により異なる（参考：150,000円程度） |
| **対象者** | 愛知県内に自ら居住する住宅所有者 |
| **対象工事** | 新規設置（既設設備との組み合わせ可） |

## 国の家庭用蓄電池補助（DR事業）

令和7年度補正「DR家庭用蓄電池事業」で最大60万円の補助も受けられます：

| 項目 | 内容 |
|------|------|
| **補助対象** | 定置用蓄電池システム |
| **上限額** | 最大60万円 |
| **対象工期** | 令和8年度中の完工 |
| **採択方式** | 公募による選定 |

## いくらもらえる？

複数制度の併用により以下の補助が期待できます：

**参考例：**
- 愛知県補助：150,000円
- 国DR補助：最大600,000円
- **合計：最大750,000円**

詳細な補助額は愛知県やPaC事務局から発表される具体的な要件をご確認ください。

## いつまでに申し込む？

- **愛知県補助:** 令和8年度継続予定（具体的な期間は愛知県から発表）
- **国DR補助:** 令和7年度補正予算分（予定日数まで）

各制度の受付開始時期は異なりますので、早めの情報確認をお勧めします。

## 申し込みのポイント

1. **愛知県補助への申請**  
   弥富市の補助窓口を通じて愛知県補助の申請が可能です。

2. **国DR補助の確認**  
   国の家庭用蓄電池補助の公募時期・条件を確認してください。

3. **太陽光発電との同時申請**  
   蓄電池単独でも申請可能ですが、太陽光発電と組み合わせるとより有利な場合があります。

4. **工事業者の選定**  
   各制度対応の工事業者から見積もりを取得してください。

## 太陽光発電との併用について

弥富市では太陽光発電と蓄電池の同時導入を支援する制度もあります。以下の効果が期待できます：

- 昼間に太陽光で発電した電気を蓄電池に貯蔵
- 夜間や天候悪化時に蓄電した電気を活用
- エネルギー自給率の向上
- 停電時の非常用電源確保
