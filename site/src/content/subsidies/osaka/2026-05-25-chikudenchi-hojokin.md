## ① 大阪市 家庭用蓄電システム補助金

### 対象者

- **大阪市内の住宅**に蓄電池を設置する個人
- 国の補助事業（環境省DRポイント補助等）の**交付決定を受けていること**が必須前提
- 市税に未納がないこと

### 補助内容

| 項目 | 内容 |
|------|------|
| **補助額** | **3万円/kWh** |
| **補助上限額** | **30万円/件** |
| 特徴 | 国補助への**上乗せ補助**（国補助と合算で大きな補助に） |

### 申請情報

| 項目 | 内容 |
|------|------|
| 受付期間 | 交付決定日〜令和9年3月31日 |
| 条件 | 国補助の**交付決定後**に申請 |
| 申請先 | 大阪市 政策企画室 |

---

## ② みんなのおうちに太陽光（共同購入支援）

大阪府・大阪市が連携して実施する**太陽光発電システムの共同一括購入事業**。グループ購入による価格交渉力で、通常より大幅に安く太陽光設備を導入できます。

| 項目 | 内容 |
|------|------|
| 割引率（令和7年度実績） | 太陽光単独：約**20.8%割引**／組み合わせプラン：約**26%割引** |
| 参加登録期間（令和8年度） | **令和8年3月18日〜9月30日** |
| 対象 | 大阪府内全域の建物所有者（太陽光10kW未満） |
| 費用 | 参加登録無料 |
| 公式サイト | おおさかスマートエネルギーセンター |

### 現金補助との違い

| 方式 | 内容 |
|------|------|
| 蓄電池補助 | 設置後に市から現金で3万円/kWh補助 |
| 共同購入 | 設置業者への支払い額が最大26%割引になる |

💡 **共同購入で太陽光を安く導入 ＋ 蓄電池は国補助＋大阪市補助** の組み合わせが最もお得です。

---

## 申し込みのポイント

1. 蓄電池補助は**国補助の交付決定が先**。まず国（環境省等）の補助申請を完了させてから大阪市に申請
2. 太陽光共同購入は登録無料・参加に拘束力なし。まず登録して見積もりを確認
3. 大阪市の「住宅省エネ改修促進事業」（窓断熱・最大70万円）と**組み合わせ可能**
4. 各区独自の補助がある場合もあるため、区役所にも問い合わせを
