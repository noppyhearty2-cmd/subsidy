## こんな事業者が対象

**松戸市内に事業所を持つ事業者**が対象です。業種・従業員数の制限はありません。

省エネルギー診断の受診や設備改修、ZEB化、EV導入など幅広い取り組みを支援します。

## 補助の内容

| 区分 | 補助率・補助上限 |
|------|----------------|
| ①省エネルギー診断の受診 | 費用全額（上限2.1万円） |
| ②省エネ診断による設備改修 | 費用の1/2（上限44万円） |
| ③ZEB購入・改修 | 費用全額（上限110万円） |
| ④電動バイク等の導入 | 費用全額（上限2万円/台） |
| ⑤電気自動車の導入 | 費用全額（上限3万円/台） |
| ⑥燃料電池自動車の導入 | 費用全額（上限5万円） |
| ⑦急速充電設備の導入 | 費用の1/2（上限40万円） |
| ⑧普通充電設備の導入 | 費用の1/2（上限10万円） |

**複数区分の組み合わせ申請も可能**です。

## 対象設備の例

- 空調・換気・照明・給湯設備（省エネ機器への入替）
- BEMS（エネルギー管理システム）
- 再生可能エネルギーシステム・蓄電システム
- ZEB対応建材・設備一式
- 電気自動車・電動バイク・燃料電池自動車
- EV充電設備（急速・普通）

## 申請スケジュール

| 項目 | 日程 |
|------|------|
| 受付開始 | 2026年4月1日（水） |
| 受付締切 | **2027年2月26日（金）** |

※Jグランツでの受付は行っていません。松戸市公式HPから申請してください。

## 申し込みのポイント

- 申請先：松戸市HP（[詳細ページ](https://www.city.matsudo.chiba.jp/kurashi/kankyou/tikyuuondanka/hojokin/ojo_mcity_office.html)）
- 省エネルギー診断（①）を受診してから設備改修（②）を行うと、2段階で補助を受けられる
- EVを複数台導入する場合は1台ごとに算出
