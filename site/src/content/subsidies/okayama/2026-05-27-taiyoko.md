## こんな方が対象

- 岡山市内の住宅に対象設備を導入する方
- **「アッシャーレ岡山エコクラブ」**への加入が必須（太陽光・蓄電池等の場合）

---

## 補助対象設備

| 設備 | 備考 |
|------|------|
| **太陽光発電システム** | — |
| **蓄電池** | — |
| **V2H充放電設備** | EVと連携した蓄電 |
| **HEMS** | エネルギー管理システム |
| **窓断熱** | 内窓・高断熱窓への交換 |
| **家庭用燃料電池** | エネファーム等 |
| **太陽熱利用設備** | — |
| **面的ZEH** | 開発全体でZEH水準 |

---

## 申請スケジュール

| 項目 | 内容 |
|------|------|
| **補助対象導入期間** | 令和8年3月1日〜令和9年2月28日 |
| **申請期間（一般）** | 令和8年5月1日〜令和9年3月10日 |
| **申請期間（面的ZEH）** | 令和8年5月1日〜令和9年3月31日 |

---

## 申し込みのポイント

1. **「アッシャーレ岡山エコクラブ」加入が必須**（岡山市の脱炭素プログラム）
2. 耐震改修補助との同年度実施も可能（要確認）
3. 国の「住宅省エネ2026キャンペーン」との併用も検討
