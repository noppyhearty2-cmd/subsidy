## こんな人が対象

- 清瀬市内の住宅を所有している方
- 既存住宅の断熱・省エネ改修を計画している方
- 耐震改修・バリアフリー化を検討している方
- 空き家の活用・改修を検討している方

## 対象となる工事

### 1. 先進的窓リノベ2026事業（国・最大200万円）

窓の断熱改修を中心とした事業：

| 工事種類 | 補助内容 |
|---------|---------|
| **内窓設置** | グレード・窓サイズに応じた補助額 |
| **外窓交換** | グレード・窓サイズに応じた補助額 |
| **ガラス交換** | グレードに応じた補助額 |
| **ドア交換** | グレードに応じた補助額 |
| **合計上限** | **最大200万円/戸** |

### 2. 長期優良住宅化リフォーム推進事業（国・最大250万円）

既存住宅を長期優良住宅に改修する事業。大規模リフォームが対象：

| 項目 | 内容 |
|------|------|
| **補助対象工事** | 断熱改修、水回り改修、耐震改修など |
| **補助率** | 工事費の1/3 |
| **上限額** | 最大250万円（大規模改修対象） |

### 3. 今住んでいる家における断熱リフォーム支援事業（国・最大120万円）

比較的手軽な断熱改修：

| 項目 | 内容 |
|------|------|
| **補助対象工事** | 壁・天井・床断熱、開口部断熱 |
| **補助率** | 工事費の1/3（上限120万円） |
| **対象期間** | 2024年11月1日～2026年12月31日 |

## いくらもらえる？

複数制度の組み合わせで、より大きな補助を受けることが可能です：

**参考例：**
- 先進的窓リノベのみ：最大200万円
- 断熱リフォーム支援事業のみ：最大120万円
- 複数制度の組み合わせ：最大1,120万円以上（東京都補助含む）

## いつまでに申し込む？

各制度により異なります：

| 制度 | 受付期間 | 備考 |
|------|---------|------|
| **先進的窓リノベ2026** | 2026年3月下旬～12月31日 | 工事着手：2025年11月28日以降 |
| **長期優良住宅化** | 通年（予算上限まで） | 先着順 |
| **断熱リフォーム支援** | ～2026年12月31日 | 予算残額による |

## 申し込みのポイント

1. **制度の選定・組み合わせ**  
   複数の制度が利用可能な場合があります。市役所で相談してください。

2. **工事着手前の申請が必須**  
   工事開始前に交付申請を行い、交付決定を受ける必要があります。

3. **登録業者の確認**  
   制度により指定業者の利用が必要な場合があります。

4. **工事内容の事前確認**  
   対象工事かどうか、補助額がいくらになるかを事前に確認してください。

## 東京都・国の補助制度との併用

清瀬市では以下の制度の組み合わせが可能：

- 東京都の省エネ補助
- 国の先進的窓リノベ2026
- 国の長期優良住宅化リフォーム
- 国の断熱リフォーム支援事業

これらを組み合わせると、工事費の大部分をカバーできる可能性があります。

## 申請手続きの流れ

1. **市役所に事前相談**  
   - 対象工事の確認
   - 利用可能な制度の確認

2. **施工業者の選定・見積もり**  
   - 登録業者から見積もり取得

3. **交付申請**  
   - 市役所に申請書類を提出
   - 国・東京都への申請（制度による）

4. **交付決定**  
   - 市役所から交付決定通知を受取

5. **工事実施**  
   - 実際の工事を実施

6. **工事完了・報告**  
   - 工事完了後、市役所に実績報告書を提出

7. **補助金受取**  
   - 指定口座に振込
