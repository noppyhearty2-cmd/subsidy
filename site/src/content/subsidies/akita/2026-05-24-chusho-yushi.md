## こんな事業者が対象

秋田市内に住所・事業所を有し、**1年以上**継続して事業を営む中小企業者（法人・個人事業主）。
市税に未納がないことが条件。

⚠️ 各資金は市・金融機関・県信用保証協会の審査があるため、申請から融資実行まで**2〜3週間**かかります。

---

## 融資制度一覧

### ① 一般事業資金（マル市）

| 項目 | 内容 |
|------|------|
| 対象 | 市内で1年以上同一事業を営む中小企業者 |
| 資金使途 | 運転資金・市内設備資金 |
| 融資限度額 | **3,000万円** |
| 融資利率 | 2.15%（固定） |
| 融資期間 | 10年以内（据置1年以内） |
| 信用保証料 | **市が全額負担** |

### ② 創業資金

| 項目 | 内容 |
|------|------|
| 対象 | 市内で初めて創業する方・創業後5年未満の個人または法人 |
| 融資限度額 | **2,000万円** |
| 融資利率 | 1.95%（基準）+ **借入から3年間1.0%の利子補給** |
| 融資期間 | 10年以内（据置1年以内） |
| 信用保証料 | **市が全額負担** |

💡 条件を満たせば、最初の3年間は実質**0.95%相当**の低利融資となります。

### ③ 創業資金（無担保・無保証人枠）

| 項目 | 内容 |
|------|------|
| 対象 | 創業予定者・創業間もない方 |
| 特徴 | **担保・保証人不要**（保証協会の特別保証が付く） |
| 信用保証料 | **市が全額負担** |

### ④ 小口零細企業資金（小口）

| 項目 | 内容 |
|------|------|
| 対象 | 小規模事業者（従業員20人以下・商業・サービス業は5人以下） |
| 特徴 | 少額から申し込めるため、創業初期にも対応 |
| 信用保証料 | **市が全額負担** |

### ⑤ 産業活力創造資金（緊急経営支援資金枠）

| 項目 | 内容 |
|------|------|
| 対象 | 経営改善・安定化に取り組む中小企業者 |
| 用途 | 経営安定化に必要な運転・設備資金 |
| 信用保証料 | **市が全額負担** |

### ⑥ 中小製造業設備資金

| 項目 | 内容 |
|------|------|
| 対象 | 市内の製造業者（チャレンジオフィスあきた入居者等） |
| 資金使途 | 設備投資資金 |
| 信用保証料 | **市が全額負担** |

## 申し込みのポイント

- 申請書は**商工貿易振興課**・秋田商工会議所・河辺雄和商工会で入手可能
- 創業資金の利子補給を受けるには**事前確認**が必要（申請書提出前に商工貿易振興課へ相談）
- 申込窓口は各取扱金融機関（秋田銀行・北都銀行・秋田信用金庫・秋田県信用組合ほか）
